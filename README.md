# 🎭 Mafia Online

نسخه شروع بازی مافیا آنلاین با Node.js و Socket.IO.

## اجرا
```bash
npm install
npm start
```

بعد مرورگر را روی `http://localhost:3000` باز کنید.

## ساختار
- `server.js` سرور بازی و ارتباط آنلاین
- `package.json` تنظیمات Node.js
- `public/index.html` صفحه بازی

## انتشار آنلاین
برای آنلاین واقعی، پروژه را روی یک سرویس میزبانی Node.js اجرا کنید و سپس لینک HTTPS آن را به بازیکنان بدهید.
