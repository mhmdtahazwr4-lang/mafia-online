# Mafia Online
نسخه‌ی پایه‌ی آنلاین بازی مافیا با Node.js + WebSocket.

## اجرا
1. Node.js نصب باشد.
2. `npm install`
3. `npm start`
4. مرورگر را روی `http://localhost:3000` باز کنید.

برای آنلاین شدن واقعی باید همین پروژه روی یک سرویس میزبانی Node.js با HTTPS منتشر شود. بعد بازیکن‌ها با لینک یکسان وارد می‌شوند.
